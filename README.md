# シューティングゲーム

ブラウザで遊べるシンプルな縦スクロールシューティングゲームです。

## 🎮 ゲームの遊び方

- **マウス操作**: マウスを動かして自機を操作してください
- **自動発射**: 敵に向かって自動で弾が発射されます
- **スコア**: 敵を撃つと10ポイント獲得
- **ゲームオーバー**: 敵が画面下部に到達するとゲームオーバーです

## 🚀 プレイ方法

1. `index.html` をブラウザで開く
2. マウスを動かして敵を回避して撃ち落とす
3. ハイスコアを目指す！

## ✨ ゲーム仕様

- **グラフィック**: レトロな配色（緑と赤）
- **難易度**: 敵が徐々に増えていく
- **操作性**: マウス操作でスムーズに動作

## 🛠️ 技術スタック

- HTML5
- CSS3
- Vanilla JavaScript
